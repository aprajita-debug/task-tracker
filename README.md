# Daily Task Tracker 📋

A simple and elegant web application to track your everyday tasks with ease.

## Features

✅ **Add Tasks** - Quickly add new tasks with categorization
📂 **Categories** - Organize tasks into Work, Personal, Health, Shopping, or Other
🎯 **Track Progress** - View statistics on total, completed, and remaining tasks
📊 **Filter Tasks** - Filter by status (Active/Completed) or category
💾 **Local Storage** - All tasks are saved automatically in your browser
📥 **Export Tasks** - Download your tasks as JSON for backup
🗑️ **Delete Tasks** - Remove individual tasks or all completed tasks at once

## How to Use

1. **Open the Application** - Open `index.html` in your web browser
2. **Add a Task** - Type your task in the input field, select a category, and click "Add Task" (or press Enter)
3. **Complete a Task** - Check the checkbox next to a task to mark it as complete
4. **Filter Tasks** - Use the filter buttons to view All, Active, Completed, or category-specific tasks
5. **Delete a Task** - Click the "Delete" button on any task to remove it
6. **Clear Completed** - Click "Clear Completed Tasks" to remove all finished tasks at once
7. **Export Tasks** - Click "Export Tasks" to download your tasks as a JSON file
